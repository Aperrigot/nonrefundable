# Nonrefundable

Appli web perso (PWA) : de l'argent en jeu sur deux habitudes (réveil, coucher).

- Front statique : GitHub Pages (ce dépôt, racine).
- Backend : Supabase (Postgres, Auth, Storage, Edge Functions, pg_cron, pg_net).
- Plan et décisions : [PLAN.md](PLAN.md).

Aucun secret dans ce dépôt. Seules l'URL du projet et la clé publishable figurent dans `config.js`.
